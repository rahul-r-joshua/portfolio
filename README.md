# 🚀 Rahul Ramasamy — Robotics & Automation Engineer

Welcome to the personal portfolio repository of **Rahul Ramasamy**, MS Scholar at IIT Palakkad specializing in **Autonomous Robotics, Navigation, Localization & Mapping, RTK-GNSS, Robot Control Systems, Motion Planning, Robotic Perception, and Sensor Fusion**.

---

## 📌 About Me & Research Specializations

- 🛰️ **RTK-GNSS & High-Precision Autonomous Navigation**:
  Deployed GNSS RTK-enabled ground rovers for centimetre-accurate autonomous navigation in agricultural vineyards at NRCG and pipeline leakage detection aerial platforms.

- 🤖 **Robot Control Systems & Digital Twins**:
  Developed complete ROS 2 frameworks for robotic manipulators with FK/IK MoveIt control, custom GUI/joystick teleoperation, and real-time Arduino hardware feedback.

- 🔄 **Autonomous Motion Planning & Kinematics**:
  Engineered Swerve Drive omnidirectional motion control in ROS 2, Mecanum wheel kinematics odometry in MATLAB, and coverage path planning with RRT/PRM algorithms.

- 🗺️ **Localization, Mapping & Robotic Perception**:
  Interfaced Intel RealSense depth sensors for ROS 2 live video telemetry and RViz2 3D spatial mapping, alongside 2D/3D LiDAR SLAM mapping in Gazebo.

- 🧠 **Adaptive Sensor Fusion & State Estimation**:
  Designed Adaptive Kalman Filter (AKF) sensor fusion algorithms integrating high-precision RTK positional data with IMU yaw orientation feedback for robust drift mitigation.

- 🛸 **Aerial & Swarm Robotics Tracking**:
  Designed flight controllers for Crazyflie quadrotors using Qualisys motion capture for real-time state feedback and multi-drone swarm coordination.
